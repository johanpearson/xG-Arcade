## 4. Priority Refactoring Targets

### 🟠 Hotspot-in-Progress (Medium-High Complexity, Rising Churn)

1. **`backend/src/XGArcade.DataSync/Wikidata/PlayerCareerPrefetchService.cs`** (408 lines, 8 commits since 2026-08-11) — unchanged this pass, still open (Epic 21 S-165). The country-sweep and club-sweep `foreach` loops in `PrefetchAsync` are ~90 lines each and near-identical in shape. **Fix:** extract a shared `SweepPoolAsync`-shaped helper both loops call, preserving every nuance verbatim — see `docs/backlog.md` Epic 21 S-165.
2. **`backend/src/XGArcade.Games.XGGrid/PlayerCacheWarmingService.cs`** (388 lines, 4 commits) — new this pass. `WarmAsync`'s Country×Club loop (~lines 169-269) and Club×Club loop (~lines 271-349) duplicate the exact same 5-branch sweep decision tree (already-valid / confirmed-low-from-sweep / confirmed-low / persistent-failure / live-query) end to end, differing only in which two `AttributeType`/name pairs and which `IWikidataLookupService` method are used — the third occurrence in this codebase of the "country/club-pair sweep" shape #1 above already flagged once. **Fix:** extract a shared `SweepPairsAsync`-shaped helper both loops call, preserving every counter and log line verbatim — see `docs/backlog.md` Epic 22 S-166.
3. **`backend/src/XGArcade.Api/CompositionRoot/CliVerbDispatcher.cs`** (769 lines, 13 commits — still the single highest-churn backend file in the repo) — new, narrower finding this pass, one level below the verb-registry shape (S-112/S-114) that's still healthy and unchanged. 5 of its 14 handlers (`HandleWarmPlayerCacheAsync`/`HandleImportPlayerNameIndexAsync`/`HandleBackfillPlayerPhotosAsync`/`HandleBackfillPlayerPositionBirthYearAsync`/`HandlePrefetchPlayerCareersAsync`) each inline the same `HttpClient`+`WikidataHttpClientConfiguration.Configure`+`WikidataClient` bootstrap — the one piece of boilerplate S-114's `BuildDbContext`/`BuildLoggerFactory` extraction didn't reach. **Fix:** extract a shared `BuildWikidataClient(ILoggerFactory, TimeSpan?)` helper — see `docs/backlog.md` Epic 22 S-167.
4. **`frontend/src/lib/*.ts`** (8 domain files, 47 `fetch` call sites) — new this pass, the frontend equivalent of #1-#3 above, only visible aggregated across the directory (no single file was ever the outlier on its own). `admin.ts`/`auth.ts`/`announcements.ts`/`leaderboard.ts`/`rounds.ts`/`leagues.ts`/`incidents.ts`/`path.ts` all hand-roll the same `fetch`+headers+`!response.ok`-check+`throwApiError`+`json()` shape at every call site; `apiClient.ts` already centralizes the error-handling half but not the request-building half. **Fix:** add a shared `apiRequest<T>`-shaped helper to `apiClient.ts` — see `docs/backlog.md` Epic 22 S-168.
5. **`frontend/src/grid/GridScreen.tsx`/`frontend/src/path/PathScreen.tsx`** (529/357 lines, 5 commits each) — new this pass.
